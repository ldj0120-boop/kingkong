⚠ 알 수 없는 상품분류 확인

아래 상품분류는 어떤 PLT 출고 카테고리(형태·공급 유사 유형)로 집계할지 자동으로 판단할 수 없습니다. 각 항목마다 취합할 카테고리를 골라주세요. 한 번 고르면 다음부터 같은 상품분류는 자동으로 같은 카테고리에 집계됩니다.

카테고리 지정 보기 / 수정

지금까지 지정한 상품분류 → 카테고리 매핑입니다. 카테고리를 바꾸거나(드롭다운) 삭제(✕)할 수 있습니다. 삭제하면 다음 업로드 때 다시 물어봅니다.
이 지정은 브라우저에 따로 저장되어 index.html을 바꿔도 유지됩니다. 다른 PC·브라우저로 옮기거나 백업하려면 아래 파일로 내보내기를 쓰세요.

① 매장 재고 업로드: "주차별 점별 PLT현황" 파일을 올리면 맨 마지막 시트만 읽어 매장별 현황을 집계합니다. (앞 주차 시트는 무시. 열 순서·추가 열이 바뀌어도 헤더명으로 맞춰 집계)
② 출고완료 실적은 이제 세 곳에서 올라옵니다 — 같은 매장·카테고리를 여러 곳이 갖고 있으면 본사 기준으로 정리됩니다:
  · 출고내역서 업로드 (센터): 날짜별 시트("260701" 등)마다 "하차지 : 매장명" 블록이 반복되는 형식.
  · 본사 출고내역서 업로드: "출고계획서" 형식(날짜별 시트, "출고지 :" 블록에 매장이 여러 개 같이 적히고 각 행에 실제 목적지가 따로 있음). 센터와 겹치는 매장·카테고리는 이 본사 값이 항상 우선합니다.
  · 가전센터 출고내역서 업로드 (방도리): "출고지 :" 블록 형식. XLK는 대형가전, XLB는 XLB로 자동 집계되며, 센터·본사와는 별도 품목이라 항상 더해집니다.
  세 형식 모두, 기존 규칙(XLA/XLB/대형가전 등)으로 못 알아보는 완전히 새로운 CATE 문구가 있으면 집계 전에 어느 카테고리로 관리할지 먼저 물어봅니다 — 한 번 답하면 다음부터 같은 문구는 자동 적용됩니다.
③ 카테고리는 "출고 입력" 화면 맨 끝 "+" 칸에서 자유롭게 추가할 수 있고, 출고완료 파일에 새 카테고리가 있으면 자동으로 추가됩니다.
④ 매출현황 업로드: "상품별 매출현황" 형식(상품분류·매장·판매수량·실매출액 열 포함)의 엑셀을 올리면 매장별로 대분류 매출이 "매장별 매출" 탭에 집계됩니다.
재고와 출고는 서로 다른 표에 각각 집계됩니다(이미 나간 출고완료 내역을 재고에 다시 더하지 않습니다). 입력값은 브라우저에만 있으니, 저장하려면 엑셀 내보내기를 눌러주세요.
